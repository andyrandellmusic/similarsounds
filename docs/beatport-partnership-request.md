Hello Beatport Partnerships team,

I'm Andy Randell, a UK DJ and producer. I run SimilarSounds (www.similarsounds.com), a free discovery tool that helps DJs find new house music that mixes well with a track they already play. It focuses on the same genres as your charts: House, Deep House, Tech House, Minimal / Deep Tech and Nu Disco / Disco.

**How it works today**
- A DJ pastes a track (including Beatport links) or types an artist. We return new releases that sound similar and mix well with it, matched on key, BPM, energy and sound.
- Every result already has a "Beatport" button that takes the DJ to the track on Beatport to buy it.
- We don't host or sell music. Previews play through official embedded players.

**What I'd like to ask**
1. **Catalogue / API access:** could SimilarSounds be approved for read-only access to the Beatport API (v4)? We'd use track genre, key and BPM so DJs see Beatport's own data next to each match, credited to Beatport. Right now we estimate these ourselves from short previews, and Beatport's data is the standard DJs trust.
2. **Affiliate or partner programme:** we'd like the Beatport buttons to count as referrals, so the traffic we send you is tracked, and to display Beatport's branding correctly.
3. **Anything else you'd want from us:** placement, attribution, linking style, or usage limits.

We're small and early, but we're built for exactly the DJs who buy on Beatport, and every match ends with a route to your store. I'd be glad to share usage figures, show you the site, or set it up however works best for you.

Thank you for your time. I look forward to hearing from you.
